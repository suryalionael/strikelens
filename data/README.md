# data/

Local-only working data. Everything in this folder is gitignored except this file
and the `.gitkeep` files.

- `raw/`: original fight videos you have the right to use locally.
- `processed/`: extracted frames, cut lists, tracks, keypoints.
- `labels/`: exported tags and training windows.

Byon Combat owns the footage. Freefly Metrics owns their tags. None of it goes in
git. See [docs/data-policy.md](../docs/data-policy.md).
